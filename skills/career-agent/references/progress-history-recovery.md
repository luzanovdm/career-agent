# Progress, history and recovery

Use the established workspace and installed context; status never starts research. Read exact case/selected packet history through query; distinguish opportunities, speculative needs, people, channels, versions, transmissions and responses. A company contact does not apply to every vacancy.

Record actual manual/user/provider observations through activity.record with exact case, occurrence time, evidence and pinned packet/version when known. Prepared is not sent; receipt is not hiring progress; bounce is not employer rejection; referral agreed is not performed. Historical pins may differ from the currently selected draft. Evidence of an actual unreviewed send is retained as such, never rewritten into preparation approval.

An uncertain action blocks another coordinated transmission until linked evidence reconciliation. Preserve its original occurrence time and selected pins. A timeout, expired lease, empty query or elapsed waiting period never proves no send. Unknown/partial channel coverage is unobserved, not silence. Keep event cutoff and evidence-check cutoff distinct in reports. Do not infer access to an inbox or complete coverage.

For lost local responses use command-status REQUEST_ID before retry. Same request ID/body returns its committed receipt; changed body conflicts. REVISION_CONFLICT means read current bounded context, preserve local edits and replan; there is no force overwrite. MATERIAL_CHANGED/REVIEW_REQUIRED preserve old bytes but block current reuse. BUSY permits bounded status/retry; never delete a live lock or kill a process by PID alone.

After partial work retain original requested scope, completed/conditional/failed IDs, current revision, selected hashes and view freshness. A valid commit survives export failure. New views never overwrite existing edited content. Rebuildable projection caches are not career truth. doctor is the explicit full integrity scan; backups use SQLite online backup, not copying an open database.

Legacy schema1/2 data is accepted only by separate offline maintenance/import_legacy.py, first on a restored disposable copy. Every source byte and historical reference receives a mapping or quarantine disposition. Strict acceptance cannot hide unresolved records. Source stays authoritative until separate reviewed writer handoff; updates never migrate candidate data. Rollback after later writes requires export/reconciliation or forward repair, never blind replacement.

A new conversation/compaction can reuse durable unchanged research authorization. Only actual pause/revocation, explicit expiry, changed scope, ambiguity or missing tools needs a new decision. Copyable UI intents are unexecuted: resolve current workspace/selection/scope and report the performed work, not the copied prompt as success.
