# Changelog

## 0.1.1

- Preserve canonical and legacy fit assessments in tracking exports without changing application outcomes.
- Check recorded target, compensation, schedule and material constraints before external discovery; reuse answers and explicit skips.
- Require current source coverage and semantic review bound to exact resume text, target and selection before counting complete packets; preserve incomplete drafts.
- Bind research permission to a bounded live operation and reconcile stopped, interrupted, expired or reopened work before resuming.

Existing version-1 candidate records remain readable. Updates do not migrate private data, start research or submit applications. Semantic quality and host cancellation still require the agent and host; forced process termination cannot guarantee cleanup.

## 0.1.0

First versioned distribution of the existing portable career workflow.

- Daily cached public release checks and explicit check requests.
- Approved, digest-verified local updates with backups and interrupted-update recovery.
- Complete portable ZIP download for hosts without writable skill installations.
- Preserve secondary career achievements instead of dropping them by role-template relevance.

Older unversioned bundles need one ordinary bootstrap update. Candidate state stays outside the skill installation; updates do not migrate private data or run job research.
