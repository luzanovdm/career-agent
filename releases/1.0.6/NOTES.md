# Career Agent 1.0.6

This patch fixes contact-disclosure validation for exact document attachments and current readiness. Valid education/calendar periods no longer masquerade as phone numbers. Explicit telephone fields remain subject to current omission/number choices through composed wrappers, field qualifiers, indexes and presentation controls; cached legacy readiness receives the same current check. Blocked attachments return structured slot/Unicode positions without exposing omitted numbers and cannot partially commit.

Immutable documents, historical reviews and transmissions are preserved. This patch does not waive independent numeric, factual, source, coverage or editorial review blocks and does not automatically approve existing drafts. It has no sender and does not retry any transmission.

Verified macOS arm64 archive only. The declared macOS 11 minimum is not tested; other platforms are not certified. Runtime, prebuilt UI and bundled Python install through the existing verified bootstrap/updater. UI, writing guidance and dependencies are unchanged.

Storage advisory carried forward: updating prevents the fixed automatic-backup growth from recurring; existing unmanaged legacy snapshots are never silently deleted. Existing occupied space may require a read-only inventory and explicitly approved cleanup. Portable/manual/migration backups remain outside automatic rotation.
