# Career Agent 1.0.2

Fix false numeric flags for names such as P2P.org, Icons8 and D3 without adding more brand exceptions. The validator now checks individual occurrences: an entity digit cannot authorize a separate count, duration or percentage. Canonical names/domains resolve automatically; the agent can declare a source-backed identifier once in its review. The readable scoped source must establish a named entity, not merely contain the same characters. Number-leading and measurement-shaped strings remain quantities even with unfamiliar units; entity metadata cannot turn another product’s price, weight or warranty into an applicant achievement. Users do not have to mark ordinary brands or erase meaningful digits.

Quantities remain tied to the actual mapped claim/scoped answer text, including signs, decimals, measurement units and repeated occurrences. One unit normalizer preserves unknown unit identity across Unicode whitespace and bounded punctuation, keeps ordinary grammatical prose separate, rejects changed currencies or durations, and recognizes supported aliases. Reference sources remain bounded and readable, with normal dependency invalidation. This is a mechanical evidence check, not a guarantee of semantic truth.

Existing partial reviews are preserved. To apply a corrected review, use the normal immutable save/review path with identical document bytes; historical versions, sending history and primary selections remain. No research, outreach, data migration or automatic approval is introduced.

This inherits the bounded verified backup repair from1.0.1. Updating does not automatically reclaim older unmanaged backups: diagnose size/free space only by read-only tools and obtain separate approval for an exact cleanup list. Portable/manual/migration archives remain outside automatic rotation.

Only native macOS arm64 has acceptance evidence; other platforms and the declared minimum OS are untested.
