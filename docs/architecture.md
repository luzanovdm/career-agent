# Career Agent 1.0 architecture

A private installed local application supports conversation and a React Aria interface. One canonical SQLite database stores normalized records and durable changes; immutable content-addressed objects store material bytes. There is one snapshot/repository/transaction owner and one typed task facade. CLI and HTTP are adapters over that facade. No author-operated service, remote database, sender or model orchestration backend is introduced.

The model supplies interpretation, evidence, prose, scoped decisions and attributable review findings. Scripts assign identities, validate structure and mechanical dependencies, assemble records, persist and report exact counts. Reusable source/claim banks preserve meaningful secondary achievements and metrics. Scoped answers distinguish unknown, confidential, declined, omit and no preference. Track overrides never silently inherit explicit unknowns.

A packet has immutable versions and an explicit selected-version pointer. A case has an explicit primary packet. Every selection projects those same bytes to chat, board/table, exports and final checks. Reviews depend on selected claims, sources, answers, recipient and semantic case/track versions. Private notes do not expire unchanged reviews. Changes to target identity or eligibility do. Included/condensed coverage resolves referenced base audits and target overlays and must bind actual resume spans; mechanical numeric/unit checks do not claim semantic understanding.

Case identity is employer plus exact opportunity keys. Reusing an existing case ID for another role fails before allocation/commit. Correcting same-role meaningful metadata changes its semantic dependency version. Contacts require independent identity, affiliation, relevance and usable-route evidence. Batch counting intersects the requested track scope and applies a typed predicate; the human criterion is a display label, not an executable natural-language rule. Changing a batch contract requires a distinct batch.

A read snapshot encloses related queries. Plans validate expected revision and stage immutable objects, and one transaction commits records, receipt, revision and durable change-log rows. Sealed plans bind exact code identity. Bounded SQLite busy timeouts return explicit retry/status guidance; uncertain sends never trigger automatic external retries.

Projection cache rows are derived and refreshed for affected records in the same transaction. Missing or expired caches rebuild explicitly. Bounded board reads share counts across six columns, use paging and verify selected material bytes on the returned page. A detected immutable-object fault downgrades all reverse-linked case projections and publishes a derived integrity signal without fabricating a career edit or review. Exact delivery fails MATERIAL_CHANGED. Restoration requires exact original bytes. Fault discovery is bounded to accessed objects; undisplayed objects are covered by explicit doctor/export verification, not an implicit whole-store scan on every UI event.

The local server serves a matching pinned asset/runtime version on loopback only. Host/Origin/CSRF/CSP and bounded route schemas prevent arbitrary SQL, filesystem or command execution. SSE replays durable CLI commits; gaps and integrity changes request revalidation, with polling fallback. Browser state contains query snapshots and dirty text, not an independently authoritative business store.

Complex UI actions render a bounded localized intent descriptor/prompt. Copy is not execution or authorization. Installed resolve-intent refreshes unrelated revisions, checks selection/scope and current permissions, and conflicts on changed selected dependencies. UI locale is canonical preference; built-in en/ru and validated mutable custom catalogs are separate from signed assets and content language.

Bootstrap verifies a complete platform archive including portable Python, staged SQLite/SSL/import self-checks, hashes, provenance and licenses. It promotes versioned installed code and switches the active locator atomically. Failed initialization restores pointers; compatible update and rollback change code under a database barrier, never silently transform business data. Normal commands execute installed code only. Development snapshots require an explicit fixture-only environment flag. The separate one-time importer never serves as a clean-runtime compatibility layer.
